# Security Policy

## Supported Versions

| Version | Supported          |
| :------ | :----------------- |
| `0.2.x` | :white_check_mark: |
| `< 0.2` | :x:                |

## Reporting a Vulnerability

We take the security of `librespot-server` seriously. If you discover a security vulnerability, please do **not** open a public issue.

Instead, please report vulnerabilities via **GitHub Private Vulnerability Reporting**:
1. Navigate to the **Security** tab of the [slaesh/librespot-server](https://github.com/slaesh/librespot-server) repository.
2. Click **Report a vulnerability** to open a confidential report.

You will receive an acknowledgment within 48 hours, followed by updates on the assessment and a timeline for a security patch.
